# Wi-Fi 接口固件代码架构

完整数据流、协议字段与 App 模块映射见 [APP_INTEGRATION.md](../../APP_INTEGRATION.md)。

| 模块 | 文件 | 职责 |
|---|---|---|
| Arduino入口 | main.ino | 委托应用层初始化与循环 |
| 调度 | src/app/fermenter_app.cpp | 串口命令、约5秒采样、CSV、网络和日志调度 |
| 状态 | src/shared/app_state.h / .cpp | 传感器、标定、温控和报警共享状态 |
| 配置 | src/config/ | 引脚、采样周期、搅拌和 MQTT 设置 |
| 采集 | src/modules/sensors/sensor_manager.cpp | DS18B20 与 TSL2591 明暗差分、空白标定 |
| pH | src/modules/sensors/ph_sensor.cpp | ADC 截尾平均、两点标定与 NVS |
| 控制 | src/modules/control/control_manager.cpp | 回差温控、过温检查、光学趋势和蜂鸣器 |
| 本地网页 | src/modules/network/network_manager.cpp | 设备热点、路由器连接、网页与 HTTP API |
| 可选远程 | src/modules/mqtt/mqtt_manager.cpp | 原有 TLS 遥测、命令和回执；默认未配置 |
| 日志 | src/modules/log/log_store.cpp | SPIFFS双文件日志、CRC检查和回收 |
| 记录格式 | src/modules/log/record_format.h | 20 字节定长记录、小端字段与 CRC |

主循环先检查温控，处理串口，再处理网页、MQTT、光学标定。约5秒到期后采集温度/pH/光学，更新控制与趋势，输出CSV。记录周期（默认120秒）到期时另写一条日志，供手机通过 HTTP 拉取。

所有 I/O 都在主循环里完成：网页请求、日志写入和执行器变更都在同一个线程，不存在跨任务竞争。日志扫描和重写期间也调用温控检查。

引脚配置与可选搅拌见 `src/config/fermenter_config.h`。默认 GPIO5 为测量 LED、GPIO6 为加热输出，搅拌禁用。历史、标定、时间轴、无效值和手机控制状态的限制详见上方对接文档。
